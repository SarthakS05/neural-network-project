# TensorFlow MNIST Neural Network

A two-hidden-layer TensorFlow Keras classifier for handwritten MNIST digits.

## Run

Use Python 3.10 with the pinned dependencies:

```bash
python -m pip install -r requirements.txt
python neural_network.py
```

Keras downloads MNIST on first run. The script trains for 2,000 steps, evaluates test accuracy, and plots sample predictions.
